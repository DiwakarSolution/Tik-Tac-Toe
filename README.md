# Colorful Tic-Tac-Toe

live:https://tik-tac-toe-gaming.netlify.app/

A responsive two-player Tic-Tac-Toe game built with HTML, CSS and vanilla JavaScript.

## Features
- Editable player names
- Two-player X/O gameplay with win and draw detection
- Scoreboard for both players and draws
- Match history with date/time
- LocalStorage persistence (scores, names and history survive refresh)
- Match timer and last-refresh timestamp
- Clear history and reset scores controls
- Responsive layout for mobile and desktop

## Run locally
1. Download and extract the ZIP.
2. Open the `Tik-Tac-Toe-Colorful` folder.
3. Double-click `index.html`, or use VS Code Live Server.

## Publish with GitHub Pages
1. Create or open your GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` (or push the extracted folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the published website link to appear in the Pages section.

## Publish with Netlify
1. Sign in at https://app.netlify.com/.
2. Choose **Add new site → Deploy manually**.
3. Drag and drop the extracted project folder.
4. Netlify will publish the site and provide a public URL.
