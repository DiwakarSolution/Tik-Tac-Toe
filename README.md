# Tic-Tac-Toe Game

A simple two-player Tic-Tac-Toe browser game built using **HTML, CSS, and JavaScript**.

## Features
- 3 × 3 interactive game board
- Alternating O and X turns
- Detects winning combinations and displays the winner
- Reset Game and New Game buttons
- No dependencies or installation required

## Technologies
- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Run locally
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Players take turns selecting squares. Get three marks in a row to win.
